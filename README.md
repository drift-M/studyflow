# StudyFlow 知页

本地优先的 AI 学习桌面应用。无需注册、不依赖云端数据库，所有学习数据都保存在你自己的电脑上。

## 下载安装（Windows）

安装包位于本仓库构建输出：`dist/studyflow-0.5.0-setup.exe`（约 132 MB，Windows 10/11 x64）。

- 双击安装，可选择安装目录；安装后自动创建桌面快捷方式
- 应用未做代码签名，首次运行时 Windows SmartScreen 可能提示「更多信息 → 仍要运行」
- 卸载应用**不会**删除学习数据（数据保存在 `%APPDATA%\StudyFlow`）；如需彻底清除请手动删除该文件夹
- 自行构建：`npm install && npm run build:win`

## 技术栈

- **桌面框架**：Electron（主进程 + 渲染进程 + preload 三层结构）
- **前端**：React 19 + TypeScript
- **构建**：Vite（通过 [electron-vite](https://electron-vite.org/) 集成）
- **本地存储**：IndexedDB（[idb](https://github.com/jakearchibald/idb) 封装，含版本管理与单元测试）
- **内容解析**：[PDF.js](https://mozilla.github.io/pdf.js/)（PDF 渲染与文本提取）、marked + DOMPurify（Markdown 渲染与净化）
- **测试**：Vitest + fake-indexeddb
- **打包**：electron-builder（Windows NSIS 安装包）

## 环境要求

- Windows 10/11
- Node.js ≥ 20（推荐 22 LTS）
- npm ≥ 10

## 当前功能（阶段 5B）

- **中文桌面界面**：侧边栏导航（首页 / 我的资料 / 知识卡片 / 练习题 / 错题本 / 设置）
- **导入学习资料**：原生文件选择框，支持 PDF 与 Markdown；只保存文件引用与元数据
- **阅读器**：Markdown 章节目录跳转；PDF 分页/跳页/缩放/按页文本提取；文件移动后可重新关联
- **生成知识卡片 / 练习题**：演示模式（本地规则提取，确定性输出）+ AI 服务接口（提示词/解析/校验已分离就绪）
- **知识卡片与间隔复习（本阶段新增）**：
  - 可解释的间隔阶梯：不熟悉 → 10 分钟后；有点印象 → 至少 1 天；已掌握 → 1 → 3 → 7 → 14 → 30 天递进
  - 「开始复习」会话逐张翻面评分，按钮上直接显示下次间隔
  - 四个视图：今日待复习 / 尚未学习 / 已掌握 / 全部
  - 统计：连续学习天数、今日已复习、掌握率
  - 复习计划持久化到 IndexedDB，重启后保持一致
- **练习题与错题本**：单选/判断自动判分、简答自评；错题自动收录、重做（答对自动已掌握）
- **★ 数据备份与恢复（本阶段新增）**：
  - 设置 →「备份与恢复」：一键导出带版本号的 JSON 备份（资料元数据、卡片与复习计划、题目、答题记录、错题、学习记录）
  - 恢复前显示各类数据的数量并要求确认；提供**合并**（不覆盖现有记录）与**替换**（清空后写入）两种策略
  - 单事务写入：恢复失败整体回滚，不会留下半份数据
  - 校验文件格式与版本：损坏文件、外来文件、更高版本备份均被拒绝并给出中文提示；无效/重复记录跳过并计数
  - **备份不包含外部 PDF / Markdown 原始文件本体**（只记录本机路径），旧版本内置内容会完整备份
  - 全程本地执行，不上传任何数据
- **设置**：数据统计、示例数据、备份恢复、清空全部数据（二次确认）

## AI 生成架构说明

```
services/
├── types.ts     # GenerationService 接口（demo 与 ai 实现同一契约）
├── demo.ts      # 演示模式：确定性规则提取（无网络、无随机数）
├── prompts.ts   # AI 提示词构建（与解析分离，已就绪待接入）
├── validate.ts  # 运行时校验：对 Demo 与 AI 输出统一执行，
│                # 格式错误给出中文提示并允许重试
└── ai.ts        # AI 适配器占位：接口/配置结构已定义，未接入真实服务
```

接入真实模型时只需实现 `GenerationService` 接口的 ai 版本；API Key 按
约定保存在主进程侧（如系统凭据库），经 IPC 引用使用，绝不写入渲染进程代码或 Git。

## 支持的文件类型与本地文件处理方式

| 类型 | 支持 | 说明 |
|---|---|---|
| `.md` / `.markdown` | ✅ 完整 | 必须为 UTF-8 编码（GBK 等编码会提示先转换） |
| `.pdf` | ✅ 阅读与文本提取 | 加密 PDF 无法打开；扫描件/图片页无法提取文本（不支持 OCR） |

**本地文件处理方式（重要）**：

- 导入时知页**只记录文件的绝对路径和元数据**，不复制、不上传文件内容；打开资料时按需从原路径读取
- 删除资料记录**不会删除**你电脑上的原始文件
- 原始文件被移动/重命名/删除后，打开会提示错误，可点「重新选择文件位置」重新关联
- 示例数据为内置内容（不依赖磁盘文件），旧版本导入的资料也保留内置内容，升级后可正常阅读
- PDF.js 所需的字体与 CMap 通过自定义协议 `pdfassets://` 从本地读取，**不访问网络**

## 数据存放位置与备份风险

知页是本地优先应用：**所有数据保存在本机 IndexedDB 中，不上传任何服务器，也没有云端备份**。

- 开发模式数据目录：`%APPDATA%\studyflow\IndexedDB`
- 安装版数据目录：`%APPDATA%\StudyFlow\IndexedDB`

⚠️ 备份与风险须知：

- **推荐备份方式**：设置 → 备份与恢复 → 导出备份文件（JSON，含全部学习数据与复习计划）
- 原始 PDF / Markdown 文件本体不在备份中，请自行妥善保存原文件
- 卸载应用不会删除数据目录；但使用系统清理工具、手动删除该文件夹会导致学习数据**永久丢失**
- 应用内「设置 → 清空全部数据」会立即删除全部本地数据

## 数据库版本迁移

- 当前版本 v4：v4 为旧卡片回填间隔复习阶梯阶段；v3 新增答题记录存储；v2 为旧记录补充 `sourcePath` / `pageCount`

## 数据模型

| 实体 | 说明 | 关键字段 |
|---|---|---|
| StudyDocument | 学习资料（PDF/Markdown） | id、标题、文件名、类型、大小、内容、导入时间 |
| KnowledgeCard | 知识卡片 | id、关联资料、正面/背面、标签、复习次数、下次复习时间 |
| QuizQuestion | 练习题 | id、关联资料、题干、选项、正确答案、解析 |
| WrongAnswer | 错题记录 | id、题目快照、我的答案/正确答案、累计次数、是否已掌握 |
| StudySession | 学习记录 | id、类型、摘要、开始时间、时长 |

## 安全说明

- `contextIsolation: true`、`nodeIntegration: false`：渲染进程页面脚本无法直接访问 Node.js
- 主进程与渲染进程只通过 preload 暴露的两个 IPC API 通信（选择文件、读取文件）
- IPC 主进程侧校验参数：类型检查、绝对路径、扩展名白名单、大小上限、PDF 文件头验证
- 页面启用了内容安全策略（CSP）；外部链接交由系统浏览器打开
- 不向渲染进程暴露 ipcRenderer 或任何通用系统能力

## 已知限制

- PDF 文本提取依赖 PDF 内嵌文字层；复杂排版的 PDF 提取顺序可能与视觉顺序不同
- 打包版（file:// 协议）下极端中文编码 PDF 的字体回退可能不完整，如遇显示问题请反馈
- 应用未签名，安装包首次运行时 Windows SmartScreen 可能提示
